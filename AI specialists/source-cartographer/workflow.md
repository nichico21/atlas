# Workflow

## Étape 1

Découverte de la source.

Entrée :

- URL

---

## Étape 2

Analyse :

- structure générale du site ;
- type de source ;
- secteurs couverts ;
- objets disponibles ;
- fréquence de mise à jour ;
- modalités d'accès.

---

## Étape 3

Production :

- source.json
- connector.json

---

## Étape 4

Validation

Le Validation Engine est exécuté.

---

## Étape 5

Correction

Si des erreurs sont détectées, le spécialiste corrige les fichiers.

---

## Étape 6

Livraison

Les fichiers sont intégrés au catalogue Atlas.
